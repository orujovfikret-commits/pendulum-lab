# Pendulum Lab Analysis

Data collection and processing for determining gravitational acceleration (g).

## Repository Scripts
- **exp.py**: Plots 3-axis gyroscope data (x, y, z) to verify planar oscillation.
- **analyze.py**: Uses FFT analysis to compute dominant period (T) and estimate frequency uncertainty bounds.

## Datasets
- **L0.21_run1.csv**: Trial run. Mislabeled as L0.50 originally; updated based on paper logbook confirmation (~21 cm length).
